5. DYNAMIC NAT — NAT POOL
   

Where to place:
    Router6 → CLI

    enable
    configure terminal

    interface gigabitEthernet 0/1
    ip nat outside
    exit

    interface gigabitEthernet 0/0
    ip nat inside
    exit

Step 2 — Create ACL:

    ip nat pool MYPOOL 209.165.100.17 209.165.100.24 netmask 255.255.255.240

    ip nat inside source list 1 pool MYPOOL overload

    end

15. IPSEC — ROUTER0
                   

Where to place:
    Router0 → CLI

Step 1 — ISAKMP policy:

    enable
    configure terminal

    crypto isakmp policy 10
    encryption aes
    authentication pre-share
    group 2
    exit

Step 2 — Pre-shared key:

    crypto isakmp key cisco123 address 20.0.0.1

Step 3 — Transform set:

    crypto ipsec transform-set SET esp-aes esp-sha-hmac

Step 4 — Crypto ACL:

    access-list 110 permit gre host 10.0.0.1 host 20.0.0.1

Step 5 — Crypto map:

    crypto map MAP 10 ipsec-isakmp
    set peer 20.0.0.1
    set transform-set SET
    match address 110
    exit

Step 6 — Apply crypto map:

    interface FastEthernet0/0
    crypto map MAP
    exit

    end
